# P05 — Maximal conjugacy-class kernel and related questions

**Directory status:** publication index only; no P05 result is included yet.

A local alternating-form or covector-rank lemma is not by itself an
exclusion of every group at the current extremal order boundary. Results
must state all hypotheses, original subgroup inequalities, rank conditions,
and whether they concern actual groups or only an associated linear model.
