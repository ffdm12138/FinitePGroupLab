# Shared — Reusable finite group-theory lemmas

**Directory status:** publication index only; no shared result is included yet.

Reusable lemmas used across multiple problems (for example `P05` and `P07`, or
general `p`-group commutator, Frattini, and cohomology helpers) are published
once here, each in its own dedicated directory `problems/Shared/<result-id>/`
with matching Lean source `FinitePGroupLab/Shared/<Module>.lean` and an explicit
entry in `releases/results.json`.
